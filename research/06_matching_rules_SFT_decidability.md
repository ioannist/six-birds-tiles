# 06 — Local/Matching Rules, Wang Tiles, SFTs, and Decidability

*Research pillar for the "shadow / strict-extension" program. This document mines the
**forcing and decidability landscape** of the LOCAL matching-rule layer (our **π₀** / the
lower-layer SFT) and pins down exactly when a finite local observer is **compelled** into the
global aperiodic (cut-and-project) structure — the **LOCAL-RULES ↔ PROJECTION bridge**. It also
assembles the ingredients for a **"rarity / forcing" argument**: almost no local rule admits a
consistent hierarchical lift.*

---

## 0. Overview and the central question

A **local rule** (equivalently, a **matching rule**, a **finite atlas of allowed patterns**, or a
set of **forbidden patterns**) is a finite, translation-invariant constraint that a finite observer
can check in a bounded window. The objects it cuts out are exactly **subshifts of finite type
(SFTs)** in symbolic dynamics, and **tilings of finite type** in the geometric setting. The
governing questions of this pillar are:

1. **Forcing of aperiodicity.** When does a finite local rule admit tilings of the plane but *force*
   all of them to be non-periodic? (Aperiodic tile sets; Berger, Robinson, Penrose, Kari–Culik.)
2. **Forcing of the higher layer (the bridge).** When does a finite local rule *force* the global
   structure to be a specific **cut-and-project / model set** — i.e. compel the lower layer into a
   particular **projection** (slope) upstairs? This is the **Levitov / Le / Bédaride–Fernique**
   theory, and it is the precise analogue of our π₀ → π₁ forcing question.
3. **Rarity.** *How rare* is a local rule that admits a consistent hierarchical / projection lift?
   The decidability obstruction (Berger) and the algebraic obstruction (Le) say: **vanishingly
   rare**, in two independent senses — computational and number-theoretic.

The headline structural facts, stated up front:

- **(Berger)** The domino problem is **undecidable** over ℤ², and undecidability *forces the
  existence of an aperiodic tile set*. ([Wikipedia](https://en.wikipedia.org/wiki/Aperiodic_tiling),
  [Jeandel–Vanier](https://www.lacl.fr/pvanier/rech/cirm.pdf))
- **(Goodman-Strauss, Annals 1998)** *Every* substitution tiling of 𝔼ᵈ, d > 1, can be **enforced by
  finite matching rules** (mild conditions). This is the **SUBSTITUTION → LOCAL-RULES bridge**.
  ([Annals 147(1):181–223](https://annals.math.princeton.edu/articles/12903))
- **(Le 1997)** A plane/slope that admits (uncolored, weak) local rules is necessarily **algebraic**
  — generated by vectors over an algebraic number field. This is the **algebraic obstruction**: the
  PROJECTION side of the bridge. ([Bédaride–Fernique restate this as Corollary 1](https://arxiv.org/pdf/1812.06863))
- **(Bédaride–Fernique 2018/2020)** A *necessary and sufficient* condition (the **coincidence**
  condition) for a generic slope to be cut out by forbidden patterns — an *effectively checkable*
  characterization of the LOCAL-RULES ↔ PROJECTION bridge.
  ([arXiv:1812.06863](https://arxiv.org/abs/1812.06863))
- **(Hochman–Meyerovitch, Annals 2010)** The entropies of ℤᵈ-SFTs (d ≥ 2) are *exactly* the
  non-negative **right-recursively-enumerable** reals — locally-admissible counting converges to the
  true value **from above**, with a genuine, uncomputable gap. This is the **SFT-counting "rarity"
  engine**. ([arXiv:math/0703206](https://arxiv.org/abs/math/0703206))

## 1. Wang tiles, the domino problem, and undecidability

### 1.1 Wang tiles and the domino problem

A **Wang tile** is a unit square with a color on each edge; tiles may be translated but **not
rotated or reflected**. Given a finite set of Wang tiles, the **domino problem** (Wang, 1961) asks:
*is there an algorithm that decides whether the set admits an edge-to-edge tiling of the whole plane,
adjacent tiles sharing a common edge color?* Equivalently, in symbolic-dynamics language, it asks
whether the **ℤ²-SFT** defined by the tile set is **non-empty**.
([Jeandel–Vanier survey](https://www.lacl.fr/pvanier/rech/cirm.pdf);
[Domino problem overview](https://en-academic.com/dic.nsf/enwiki/7547733))

Wang **conjectured** the problem was decidable, via the (false) assumption that *every tile set that
tiles the plane also admits a periodic tiling*. If that were true, one could dovetail two
semi-decision procedures — searching for a periodic tiling and searching for a finite blocking patch
— and always halt.
([Fernique–Sablik](https://arxiv.org/pdf/1208.2759))

### 1.2 Berger's theorem (1966): undecidability ⇒ aperiodic sets exist

**Berger's theorem.** *The domino problem is undecidable.* The proof has **two ingredients**
([Fernique–Sablik](https://arxiv.org/pdf/1208.2759),
[Wikipedia](https://en.wikipedia.org/wiki/Aperiodic_tiling)):

1. **Turing simulation.** A Turing machine's space-time diagram is encoded by Wang tiles, so that
   tilings of a region correspond to halting/non-halting computations. Deciding tileability would
   decide the halting problem.
2. **An aperiodic tile set.** To run (1) the construction must *force* a non-periodic background
   scaffold on which computations are laid out. Berger thus had to exhibit a finite tile set that
   **tiles the plane but only non-periodically** — the first **aperiodic tile set**.

The logical punchline relevant to us: **undecidability *forces* the existence of an aperiodic tile
set.** If every tiling tile set were "eventually periodic," the problem would be decidable; since it
is not, some tile set must admit only non-periodic tilings.

> Terminology (Wikipedia stresses this is widely abused): an **aperiodic set of prototiles** is a
> finite set that admits tilings but *no* periodic tiling; an **aperiodic tiling** is the resulting
> pattern. ([Wikipedia](https://en.wikipedia.org/wiki/Aperiodic_tiling))

Berger's first set had **20,426** Wang tiles, later reduced (in his thesis) to **104**.
([Wikipedia](https://en.wikipedia.org/wiki/Aperiodic_tiling))

### 1.3 Robinson's tiles (1971): hierarchical forcing made transparent

Raphael Robinson (1971) simplified Berger to **6 tiles** (up to rotation/reflection), with
triangular **bumps/dents** and oriented **arrows**. The tiles force a **hierarchy of nested square
lattices**: tiles assemble into 2×2 blocks, which assemble into larger blocks, etc., a structure
proved by induction. The forcing is explicitly **hierarchical** — exactly the mechanism Berger and
Robinson "used in a very strong way."
([Robinson 1971, Invent. Math. 12:177–209](https://users.cs.duke.edu/~reif/courses/molcomplectures/TilingAssembly/TilingComputability/UndecidabilityTilingRobinson.pdf);
[Wikipedia](https://en.wikipedia.org/wiki/Aperiodic_tiling);
["Yet Another Proof of the Aperiodicity of Robinson Tiles", arXiv:1711.03401](https://arxiv.org/pdf/1711.03401))

This hierarchical scaffold is the local-rules incarnation of "the higher layer is forced": a finite
local observer that obeys Robinson's matching rules is *compelled* into the infinite nested-square
hierarchy — the local rule has no consistent non-hierarchical completion.

### 1.4 Kari–Culik (1995–96): small sets with a *non-hierarchical* mechanism

Kari (14 tiles, 1996) and Culik (**13 tiles**, 1996 — the current smallest known) gave aperiodic sets
whose aperiodicity proof is **number-theoretic, not hierarchical**: the tiles simulate a
**piecewise-multiplicative dynamical system** ("Mealy/sequential machines multiplying balanced
real representations by rational constants"), built from **Beatty sequences**, with parameters chosen
so the dynamics has **no periodic orbit**.
([Culik, "An aperiodic set of 13 Wang tiles", Discr. Math. 160 (1996)](https://www.sciencedirect.com/science/article/pii/S0012365X96001185);
[Eigen–Navarro–Prasad, SLMath](https://library.slmath.org/books/Book54/files/08eigen.pdf);
["A Minimal Subsystem of the Kari–Culik Tilings", arXiv:1410.1572](https://arxiv.org/abs/1410.1572))

> This matters for our program: there exist forced-aperiodic local rules whose forcing is **arithmetic
> rather than hierarchical**. A "forcing of the higher layer" claim must therefore either (a) restrict
> to the hierarchical/substitution class, or (b) absorb the arithmetic mechanism into the notion of
> "higher layer."

### 1.5 The Jeandel–Rao threshold and the geometric monotiles

- **Jeandel–Rao (2015/2021):** an aperiodic set of exactly **11 Wang tiles** exists, and **every set
  of ≤ 10 Wang tiles is periodic** (or fails to tile). This is the exact threshold for Wang-tile
  aperiodicity. ([arXiv:1506.06492](https://arxiv.org/pdf/1506.06492))
- **Hat & Spectre (Smith–Myers–Kaplan–Goodman-Strauss, 2023):** the first **aperiodic monotiles** in
  the plane. The **Hat** is a 14-edge polykite; crucially it is **"entirely geometric — no additional
  matching rules are required"** (aperiodicity is forced by *shape alone*, though reflections are
  needed). The **Spectre** is a chiral monotile needing no reflections.
  ([arXiv:2303.10798](https://arxiv.org/pdf/2303.10798);
  [arXiv:2305.17743](https://arxiv.org/abs/2305.17743);
  ["Planar aperiodic tile sets: from Wang tiles to the Hat and Spectre", arXiv:2310.06759](https://arxiv.org/html/2310.06759v2))

> For our project's "monotile = shadow of a higher layer" framing, the Hat/Spectre are the targets:
> the matching rule is *dissolved into the shape*, i.e. π₀ becomes "shape-only adjacency," yet the
> higher (substitution/projection) layer is still forced.

## 2. Matching rules forcing aperiodicity: strong vs weak, colored vs uncolored

### 2.1 What "local rules enforce a tiling" means

A tiling space cut out by *forbidden patterns of bounded radius* is of **finite type**; if instead
we cut it out by **decorated/colored tiles that must match** (Wang-style) and then *erase the
decorations*, we get a **sofic** space. Formally
([Fernique–Sablik, "Weak Colored Local Rules", arXiv:1603.09485, §2.2](https://arxiv.org/pdf/1603.09485)):

> "Colored local rules are actually equivalent to so-called matching rules, where tiles are decorated
> (e.g. by coloring edges) and allowed to fit together only if their decorations match… Any finite
> type tiling space is sofic but **the converse does not always hold**."

This **SFT ⊊ sofic** gap is the symbolic-dynamics shadow of "decoration lets local rules say more
than bare geometry can" — and, as we note in §6, it is precisely the **fiber-collision** phenomenon
our F8 certificate detects.

### 2.2 Penrose's arrows / decorations

The rhombic Penrose tiling uses two rhombi marked with **single and double arrows** (equivalently
colored edges, or matching red/green arcs); tiles must be edge-to-edge with **arrows/arcs matching**.
This *colored strong local rule* forces a tiling that is **necessarily non-periodic** (bare
unmarked rhombi *do* admit periodic tilings — the markings are doing the forcing).
([Tilings Encyclopedia: Matching Rules](https://tilings.math.uni-bielefeld.de/glossary/matching-rules/);
[Wikipedia](https://en.wikipedia.org/wiki/Aperiodic_tiling))
De Bruijn (1981) showed Penrose-by-rhombi is the **digitization of a 2-plane in ℝ⁵** built on the
golden ratio (vectors over ℚ[√5]) — the first explicit instance of the LOCAL-RULES ↔ PROJECTION
bridge. ([Fernique–Sablik §2.4](https://arxiv.org/pdf/1603.09485))

### 2.3 The strong / weak / weakened taxonomy (Levitov 1988; Fernique–Sablik)

Levitov introduced **strong** vs **weak** local rules; Fernique–Sablik add **weakened**. Let *E* be a
set of d-planes (slopes) in ℝⁿ. A set **F** of local rules with **thickness** t ≥ 1 *enforces* E if
([arXiv:1603.09485, §2.2](https://arxiv.org/pdf/1603.09485)):

- For each E ∈ *E*, the SFT X_F contains a **planar** tiling of thickness ≤ t with slope ∥ E; and
- X_F contains **only** planar tilings (of thickness t) with slope ∥ some element of *E*.

Then:
- **Strong local rules:** t = 1 in **both** conditions — the lift stays within unit distance of the
  plane (true digitization).
- **Weak local rules:** t = 1 in the *first* only — admitted tilings stay within *bounded* (but
  possibly > 1) distance of a plane; "fattened" lifts allowed.
- **Weakened local rules:** general t (Fernique–Sablik's intermediate notion).

> Note (the authors stress): X_F need *not* contain *all* planar tilings of slope E — "this is why we
> prefer to say that local rules **enforce planes, not tilings**." This is exactly the distinction
> between *forcing the higher-layer structure* (the slope / projection) and *forcing one specific
> shadow*.

A second axis is **colored vs uncolored** (sofic vs SFT). The four-cell taxonomy
([arXiv:1603.09485, §2.4](https://arxiv.org/pdf/1603.09485)):

| | **Uncolored (SFT)** | **Colored (sofic / matching rules)** |
|---|---|---|
| **Strong** | Penrose, Ammann–Beenker (Beenker 1982); Levitov necessary condition (rational dependency among slope-vector entries) | de Bruijn (Penrose, ℚ[√5]); Socolar; substitution tilings (Mozes; Goodman-Strauss; Fernique–Ollinger) — *algebraic slopes only* |
| **Weak** | Levitov sufficiency (R⁴, generalized Penrose, icosahedral); **only quadratic slopes** in 2-planes of ℝ⁴ (Bédaride–Fernique); **Le's algebraic obstruction** | Le–Piunikhin–Sadov (any quadratic plane of ℝᵏ); Le–Piunikhin (quadratic d-planes of ℝ²ᵈ); **Fernique–Sablik: recursively-closed ⇔ enforceable** |

## 3. The LOCAL-RULES ↔ PROJECTION bridge (Levitov · Le · Bédaride–Fernique)

**This is the central section for the program.** It answers: *when does a finite local rule force the
cut-and-project (model) set — i.e. compel π₀ into a particular projection upstairs?*

### 3.1 Cut-and-project / canonical projection tilings (the "upstairs")

A **canonical projection tiling** is the digitization of a d-dim. affine subspace **E** ("the slope")
of ℝⁿ: lift the tiling to a "stepped" d-manifold in ℝⁿ that stays inside the tube **E + [0,1]ⁿ**; the
slope is recovered up to translation. The family includes Sturmian words (lines in ℝ²), billiard
words (ℝ³), Ammann–Beenker (2-planes in ℝ⁴), Penrose (2-planes in ℝ⁵), icosahedral (3-planes in ℝ⁶).
**Irrational slope ⇒ aperiodic; rational ⇒ periodic** — exactly the project's "shadow at irrational
orientation" picture.
([Bédaride–Fernique, arXiv:1812.06863, §1–2](https://arxiv.org/pdf/1812.06863))

A slope E is **characterized by patterns** (= "admits local rules" = "is an SFT") if there is a finite
set of *forbidden* patterns such that *any* canonical projection tiling (with generic slope) avoiding
them has slope **parallel to E**. ([arXiv:1812.06863, §1](https://arxiv.org/pdf/1812.06863))

### 3.2 Levitov (1988): the first algebraic conditions

Levitov studied the relation of *local order* to *long-range order*, coining **strong/weak** local
rules. His necessary conditions for **strong** local rules reduce to **arithmetic constraints among
the incommensurabilities** of the quasicrystal — a "rational dependency between the entries of the
vectors generating the slope." For planar quasicrystals, **quadratic irrationalities** play the
decisive role; weak local rules exist for almost all quadratic-based 2D quasicrystals and for the
icosahedral one.
([Levitov, *Commun. Math. Phys.* 119:627 (1988)](https://projecteuclid.org/journals/communications-in-mathematical-physics/volume-119/issue-4/Local-rules-for-quasicrystals/cmp/1104162600.pdf);
restated in [Fernique–Sablik §2.4](https://arxiv.org/pdf/1603.09485))

### 3.3 Le–Piunikhin–Sadov (1992) and Le–Piunikhin (1995): quadratic ⇒ rules exist

**Le–Piunikhin–Sadov (*Commun. Math. Phys.*, 1992):** **every quadratic plane of ℝᵏ admits colored
weak local rules.** Concretely, strip/projection tilings of the plane always admit local rules when
the embedding ℝ² ↪ ℝ⁴ has **quadratic** coefficients. Le–Piunikhin (1995) extended this to **quadratic
d-planes of ℝ²ᵈ**.
([Le–Piunikhin–Sadov, *CMP* 1992](https://link.springer.com/article/10.1007/BF01218348);
[Le–Piunikhin, "quadratic 2-planes in ℝ⁴", *CMP* 1995](https://link.springer.com/article/10.1007/BF02096563);
restated in [Fernique–Sablik §2.4](https://arxiv.org/pdf/1603.09485))

This is the **sufficiency** direction: a number-theoretically "nice" (quadratic) projection *can be
forced* by a finite local rule.

### 3.4 Le (1997): the algebraic obstruction — the necessity direction ★

**Le's theorem (1997).** *If a (generic) slope admits weak local rules, then it is **algebraic** —
generated by vectors whose entries lie in a common algebraic number field.*
([T.T.Q. Le, "Local rules for quasiperiodic tilings", in *The Mathematics of Long-Range Aperiodic
Order*, NATO ASI C-489, Kluwer 1997, pp. 331–366];
restated as **Corollary 1** in [Bédaride–Fernique, arXiv:1812.06863, §4](https://arxiv.org/pdf/1812.06863):)

> **Corollary 1 (Bédaride–Fernique, after Le97).** *Any slope in G₀(n,d) characterized by patterns is
> algebraic.*

Le further **conjectured** that for 2-planes the field must be **quadratic**; this was confirmed for
2-planes of ℝ⁴ by Bédaride–Fernique (only quadratic slopes admit uncolored weak local rules — see
§3.6). ([Fernique–Sablik §2.4](https://arxiv.org/pdf/1603.09485);
[n-Category Café on quasicrystals ↔ PV numbers](https://golem.ph.utexas.edu/category/2013/06/quasicrystals_and_the_riemann.html))

> **★ This is the heart of the "rarity" argument on the projection side.** The slopes are a
> continuum (a Grassmannian); the slopes that *admit local rules* are confined to the **measure-zero,
> countable algebraic locus**. **Almost every projection direction is un-enforceable by any finite
> local rule.** A local observer can be compelled into a projection structure *only* at algebraic
> (and conjecturally, for 2-planes, quadratic) slopes — the same Pisot/quadratic locus that
> APPROACH.md identifies as the project's "non-descending object."

### 3.5 Bédaride–Fernique (2018/2020): a necessary-and-sufficient *checkable* characterization ★

This is the sharpest form of the bridge. Define a **coincidence** of a slope E ⊂ ℝⁿ
([arXiv:1812.06863, Def. 1, §3](https://arxiv.org/pdf/1812.06863)):

> **Definition 1.** A *coincidence* of a d-plane E ⊂ ℝⁿ is a set of n−d+1 pairwise non-parallel unit
> (n−d−1)-dim. faces of ℤⁿ whose projections (into the internal window W_E) are **concurrent**.

E is **characterized by coincidences** if it is the *only* generic slope admitting all of them. Each
coincidence is a **rational polynomial equation on the Grassmann (Plücker) coordinates** of E
(Prop. 2), homogeneous of degree n−d (Prop. 3) — hence the condition is a **finite, decidable check
in computer algebra** (does a polynomial system have finitely many solutions / is the variety
zero-dimensional). The main theorem:

> **Theorem 1 (Bédaride–Fernique).** *A slope in G₀(n,d) is **characterized by patterns** if and only
> if it is **characterized by coincidences**.*

with the immediate **Corollary 1** of §3.4 (patterns ⇒ algebraic). The companion paper "When
Periodicities Enforce Aperiodicity" (Bédaride–Fernique, *CMP* 2017) recasts coincidences as
**subperiods**:

> **Theorem 1 (arXiv:1309.3686).** *Subperiods of a codimension-two rhombus tiling enforce irrational
> planarity iff three of them … can be lifted in an irrational non-degenerate plane onto pairwise
> non-collinear vectors.* ⟹ **Corollary 1:** *if the subperiods characterize finitely many slopes, the
> tiling admits local rules.*
> ([arXiv:1309.3686](https://ar5iv.labs.arxiv.org/html/1309.3686))

> **★ Operationally, this is the bridge our program needs as an oracle:** given a candidate higher
> layer (lattice + slope), Theorem 1 turns "does π₀ force this projection?" into a *finite Gröbner /
> Plücker-equation check*. The forcing of the higher layer is **decidable for a fixed projection
> family**, even though the global domino problem is not.

### 3.6 Negative results: when no local rules exist (the rarity made concrete)

- **No weak local rules for 4p-fold tilings.** Planar tilings with **n-fold** symmetry admit (simple,
  uncolored) weak local rules iff **n is not a multiple of 4**: positive for odd n (Socolar 1990) and
  shown *impossible* for n ≡ 0 (mod 4) — first n = 8 (Burkov 1988), then all multiples of 4
  (Bédaride–Fernique). So the very symmetric octagonal/8-fold case is **not** enforceable.
  ([Bédaride–Fernique, "No Weak Local Rules for the 4p-Fold Tilings", *DCG* 2015](https://link.springer.com/article/10.1007/s00454-015-9740-8);
  [HAL PDF](https://hal.science/hal-01219081/file/Bedaride-Fernique-4n.pdf))
- **Only quadratic slopes** among 2-planes of ℝ⁴ admit uncolored weak local rules (Bédaride–Fernique),
  confirming Le's quadratic conjecture in that case.
  ([Fernique–Sablik §2.4](https://arxiv.org/pdf/1603.09485))
- **Colored weak local rules reach the computability barrier.** Allowing *decorations*, the
  obstruction lifts all the way from "algebraic" to "computable":

> **Theorem 1 (Fernique–Sablik, "Weak Colored Local Rules").** *A set of planes is enforced by colored
> weak local rules **iff** it is **recursively closed**.* (Equivalently for a single plane: iff its
> parameters are **computable**.) ([arXiv:1603.09485, §2.4](https://arxiv.org/pdf/1603.09485);
> companion: [Fernique–Sablik, "Local Rules for Computable Planar Tilings", arXiv:1208.2759, Thm 1](https://arxiv.org/pdf/1208.2759))

> **Interpretation of the colored/uncolored gap.** *Uncolored* (bare SFT) ⇒ **algebraic** slopes only
> (Le). *Colored* (sofic, decorations allowed) ⇒ **computable** slopes — strictly more, but still
> measure-zero. **Decoration is exactly the extra power that the sofic-but-not-SFT gap provides** — it
> is the local-rules analogue of "the lower layer needs a hidden internal state (the hierarchy /
> projection coordinate) to be forced." This is the formal mirror of our **strict-extension /
> non-factorization** picture (§6).

## 4. The SUBSTITUTION ↔ LOCAL-RULES bridge (Goodman-Strauss)

The other leg of the triangle (substitution ⟷ projection ⟷ local rules). Whereas §3 connects local
rules to *projections*, Goodman-Strauss connects local rules to *substitutions*.

**Goodman-Strauss (*Annals of Mathematics* 147(1):181–223, 1998).** Abstract:

> "A substitution tiling is a certain globally defined hierarchical structure in a geometric space; we
> show that for any substitution tiling in 𝔼ᵈ, d > 1, subject to relatively mild conditions, one can
> construct local rules that force the desired global structure to emerge."
> ([Annals 147(1):181–223](https://annals.math.princeton.edu/articles/12903))

In words: **every substitution tiling admits finite matching rules** (the local rules *enforce* the
substitution — any tiling obeying the rules is admitted by the substitution). **Corollary:** infinitely
many distinct **forced aperiodic** tilings. The result subsumes all previously known hierarchical
aperiodic tilings.
([Goodman-Strauss talk, "Aperiodic Hierarchical Tilings"](https://strauss.hosted.uark.edu/distribution/talks/aperiodicity.pdf))

**The "mild condition."** Tiles must admit a system of **"hereditary edges"** so the substitution is
**"sibling edge-to-edge"** (sufficiently consistent across the inflation hierarchy).
([Tilings Encyclopedia](https://tilings.math.uni-bielefeld.de/glossary/matching-rules/))

**Modern restatement (Vereshchagin 2025, "Goodman-Strauss theorem revisited").** The original
"sufficient conditions are scattered throughout the proof"; Vereshchagin makes them explicit and casts
"enforce with finite matching rules" as **soficity**:

> A family of tilings is **sofic** if one can color the sides of prototiles, decorate each prototile in
> several ways, define "proper" (side-to-side, color-matching) decorated tilings, and prove that an
> undecorated tiling is in the family **iff** it is the projection (decoration-erasure) of a proper
> decorated tiling.
>
> **Theorem 3.** *If a substitution τ satisfies R0 and some power admits a markup satisfying R1–R8,
> then the families of τ-hierarchical and τ-substitution tilings are both **sofic**.* (R0: supertiles
> side-to-side; R8: the "2/3 requirement" — in any non-central type, fewer than 2/3 of sides lie on
> the net.) These hold for "almost every" substitution after taking a power and merging tiles.
> ([arXiv:2510.02842](https://arxiv.org/html/2510.02842v1))

> **Why this matters to the program.** Goodman-Strauss says the SUBSTITUTION (one of APPROACH.md's two
> charts) is *always* shadowed by local rules. Combined with §3, the **substitution chart** and the
> **projection chart** are *both* enforceable by π₀ — but only on the **algebraic/Pisot locus** (§3.4,
> §3.6), since substitution slopes are algebraic. The two charts meet at exactly the Pisot/quadratic
> directions, matching F41 (duality) and the project's Pisot linkage.

> **Caveat (Kari–Culik, §1.4).** Not every forced-aperiodic local rule comes from a substitution: the
> Kari–Culik mechanism is arithmetic and **"has no known hierarchical explanation."** So
> *substitution ⇒ local rules* (Goodman-Strauss) is **not** an equivalence; local rules are strictly
> more expressive than substitutions, in the same direction that sofic is more than SFT.

## 5. Subshifts of finite type: definitions, the ℤᵈ case, and counting/entropy

### 5.1 Definitions

For a finite alphabet 𝒜 and group/lattice ℤᵈ, the **full shift** is 𝒜^(ℤᵈ) with the shift action. A
**subshift of finite type (SFT)** is the set of configurations avoiding a **finite** list of forbidden
patterns. A **sofic shift** is a *letter-to-letter (continuous, shift-commuting) image* of an SFT —
equivalently the *erasure of decorations* from an SFT. Wang-tile sets are exactly **nearest-neighbor
ℤ²-SFTs**; matching rules with erased colors give **sofic** ℤ²-shifts.
([Fernique–Sablik §2.2](https://arxiv.org/pdf/1603.09485);
[Vereshchagin](https://arxiv.org/html/2510.02842v1))

**Key inclusion: every SFT is sofic, but not conversely.** This is the single most important structural
fact for our forcing question (see §6).

### 5.2 Locally vs globally admissible — the gap that *is* the forcing

- A pattern is **locally admissible** if it contains no forbidden pattern (a *local* observer cannot
  rule it out).
- A pattern is **globally admissible** if it actually extends to a full configuration in the subshift
  (it is consistent with the *global* law).

**Globally admissible ⇒ locally admissible, but not conversely** — and the gap can be *arbitrarily
large and uncomputable*. ([symbolic-dynamics overview, search synthesis];
[Hochman–Meyerovitch, Annals 2010](https://annals.math.princeton.edu/wp-content/uploads/annals-v171-n3-p12-p.pdf))

For our program this gap **is** the forcing of the higher layer: a finite π₀-legal patch
(locally admissible) need not be globally admissible; whether it extends is governed by the
hierarchical/projection law π₁. *The local observer that respects π₀ is compelled into π₁ precisely
because most locally-admissible patches are globally inadmissible.*

### 5.3 The dimension jump in decidability (the abstract restated dynamically)

- **ℤ¹ (one dimension):** the SFT emptiness / domino problem is **decidable** — reduce to a finite
  graph and check for a bi-infinite path (a cycle). Entropy of an irreducible ℤ¹-SFT is **computable**
  (log of the Perron root, an algebraic number).
- **ℤ² and above:** SFT emptiness (the domino problem) is **undecidable** (Berger), and this is *the*
  source of aperiodicity (§1.2). ([Fernique–Sablik](https://arxiv.org/pdf/1208.2759);
  [Jeandel–Vanier](https://www.lacl.fr/pvanier/rech/cirm.pdf))

### 5.4 Entropy: locally-admissible counting overshoots — Hochman–Meyerovitch ★

The **topological entropy** of a ℤᵈ-SFT is
h = lim_{n→∞} (1/nᵈ) · log N(n), where N(n) counts patterns on the n×···×n cube. There are *two*
counts: locally-admissible ones (computable, by checking forbidden patterns) and globally-admissible
ones (in general not). The sharp result:

> **Hochman–Meyerovitch (*Annals* 171(3), 2010).** *A non-negative real h is the entropy of a ℤᵈ-SFT
> (d ≥ 2) **iff** h is **right recursively enumerable** — i.e. there is a computable sequence of
> rationals **converging to h from above**.* The same class arises for sofic shifts; for an
> **irreducible** SFT the entropy is **computable**.
> ([arXiv:math/0703206](https://arxiv.org/abs/math/0703206);
> [Annals PDF](https://annals.math.princeton.edu/wp-content/uploads/annals-v171-n3-p12-p.pdf))

The mechanism is exactly our point: **counting locally-admissible n-cubes converges to h *from
above*** — it systematically *overestimates*, because most locally-legal patterns are globally
illegal, and the deficit need not be computable. The "from above" direction is the entropy signature
of **local admissibility over-counting global admissibility.**

> The complementary "rarity" statement at the *border*: for any ℤ²-SFT the number of **globally**
> admissible k×k patterns grows like 2^O(k) (controlled by the *boundary* length k, not the area k²);
> for a genuine *sofic* shift this can fail and log Nₖ can grow faster than the border. This boundary
> vs area dichotomy is another quantitative form of "local-admissible ≫ global-admissible."
> ([Hochman–Meyerovitch](https://annals.math.princeton.edu/wp-content/uploads/annals-v171-n3-p12-p.pdf))

## Relevance to our shadow / strict-extension approach

This pillar supplies the **formal skeleton** for the project's reframe ("the tile is the shadow; the
work is upstairs", APPROACH.md) and turns three of our structural laws into *theorems with addresses*.

### A. π₀ **is** the local SFT layer; the higher layer **is** the projection — and the two are bridged
Our **π₀** (the local-plane / matching-rule map) is precisely a **ℤ²-SFT (or sofic shift)**; the higher
**π₁** (the hierarchical / cut-and-project map) is precisely a **canonical-projection tiling / model
set**. The **LOCAL-RULES ↔ PROJECTION bridge** of §3 is therefore *literally* the π₀ → π₁ relation:

- **Le's obstruction (§3.4):** π₀ can force π₁ **only at algebraic slopes** — a measure-zero, countable
  locus inside the continuum of directions. This *is* APPROACH.md's "non-descending object `U` = the
  irrational projection direction": the directions that *survive as forced shadows* are exactly the
  algebraic (Pisot/quadratic) ones the program walks toward.
- **Bédaride–Fernique (§3.5):** turns "does π₀ force this projection?" into a **finite, decidable
  Plücker/coincidence check**. This is an explicit, runnable **audit oracle** for the F8 certificate
  on the projection chart — "does the local rule pin down this slope and only this slope?"
- **Goodman-Strauss (§4):** the **substitution chart** (the dual chart, F41) is *always* shadowed by
  local rules. So *both* charts in APPROACH.md descend to π₀, and they coincide on the **Pisot/quadratic
  locus** — matching the project's "Pisot links the two charts."

### B. The FORCING of the higher layer = the locally-admissible vs globally-admissible gap
The certificate (F8 / Foundations III Thm 12): *π₁ does **not** factor through π₀ ⟺ two patches with
π₀ equal but π₁ different* — "local indistinguishability + globally forced hierarchy." This is **exactly
the symbolic-dynamics gap of §5.2 and the SFT ⊊ sofic gap of §5.1**:

- "Two patches with π₀ equal but π₁ different" = **two locally-admissible patches that lie in different
  global fibers** = the **decoration (hidden state) cannot be read off the bare local pattern**. That is
  the defining feature of a shift that is **sofic but not SFT** — the erased decoration is the
  hierarchy/projection coordinate.
- Hence **"π₁ does not factor through π₀"** is the assertion that the system is **sofic-but-not-of-finite-type**, with the *fiber collision* (equal π₀, split π₁) being the witness. The forcing of
  the higher layer is real precisely when this gap is non-trivial — and §3.4/§3.6 say it is non-trivial
  on a *thin algebraic set* and trivial (no rules at all) generically.

### C. A concrete SFT-counting **"rarity / forcing"** argument (two independent rarities)
The brief asks for "almost no local rule admits a consistent hierarchical lift." Two independent,
citable rarity engines support this, and a counting argument can be assembled from §5.4:

1. **Number-theoretic rarity (Le, §3.4; Bédaride–Fernique, §3.6).** Among the continuum of slopes, the
   ones admitting (uncolored) local rules form the **measure-zero algebraic locus** — and for 2-planes
   of ℝ⁴, only the **quadratic** locus. *Almost every projection is un-enforceable.* The set of local
   rules that *do* pin a projection is correspondingly thin.
2. **Computational/entropy rarity (Hochman–Meyerovitch, §5.4).** For a candidate local rule (ℤ²-SFT),
   the count of **locally-admissible** n-cubes overestimates the count of **globally-admissible** ones,
   converging to the entropy **strictly from above**, with an **uncomputable deficit** in general. A
   "rarity" lemma in our setting reads:

   > *The fraction of locally-admissible (π₀-legal) patches that admit a consistent global hierarchical
   > lift (π₁) tends to a value governed by the from-above entropy gap; for a rule that genuinely forces
   > a hierarchy this fraction → 0 (the boundary-vs-area dichotomy of §5.4: globally-admissible counts
   > are controlled by the boundary k, while locally-admissible counts grow with the area k²).*

   In slogan form: **a finite π₀-observer is "almost always" looking at a patch that has *no* global
   completion — so the rare patches that *do* complete are forced into the single global hierarchy.**
   That over-count-from-above is the quantitative content of "the higher layer is forced."

3. **Decidability rarity (Berger, §1.2).** The map "(local rule) ↦ (does it tile / lift)?" is
   **undecidable** (Π⁰₁-complete). There is *no* finite syntactic certificate of *generic* liftability —
   which is exactly why our certificate must instead target the **forced, non-factoring** case (§B):
   forcing of the higher layer is *not* a property one can read off by pattern-matching, consistent with
   the program's insistence that the audit is a *downward shadow check*, not a search.

### D. What this pillar hands the constructor (actionable)
- **An oracle for the audit on the projection chart:** Bédaride–Fernique Theorem 1 — a finite
  Gröbner/Plücker computation deciding whether a candidate higher layer's slope is *pinned by local
  rules* (the runnable form of F33/F8 on the projection side).
- **A target locus:** the **algebraic, conjecturally quadratic/Pisot** slopes (Le; Bédaride–Fernique;
  the 2026 cocycle paper's Pisot conjecture) — the only directions where a forced single-prototile
  shadow can exist. The **Hat/Spectre** (§1.5) show the endgame: the matching rule **dissolved into
  shape** while the higher layer remains forced.
- **A rarity backbone:** the from-above entropy gap (Hochman–Meyerovitch) + the algebraic obstruction
  (Le) jointly justify "almost no local rule lifts," i.e. the higher layer, *when present*, is
  **forced** rather than merely *consistent* — the precise statement our strict-extension certificate
  is built to confirm.
